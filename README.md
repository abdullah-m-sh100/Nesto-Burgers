## 📌 Overview

**Nesto Burgers** is a modern smash burger restaurant website designed to showcase the restaurant’s menu, special offers, and brand identity while providing customers with an easy and enjoyable browsing experience.

The website supports both **Arabic and English**, including automatic **RTL/LTR layout switching**, ensuring accessibility for a wider audience.

---

## ✨ Key Features

* 🌍 Full Arabic & English language support
* ↔️ Automatic RTL / LTR direction switching
* 🛒 Interactive shopping cart system
* 🍔 Dynamic menu filtering by category
* 📱 Fully responsive on all devices
* ⚡ Fast-loading and optimized performance
* 🎨 Modern UI with a strong burger-brand identity
* 📞 Direct ordering via WhatsApp
* 🔍 Smooth user experience and intuitive navigation

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Abdullah-m-sh100/Nesto-Burgers.git
```

### Navigate to the Project Directory

```bash
cd Nesto-Burgers
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```
